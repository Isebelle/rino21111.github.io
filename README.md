# Apartment Designer

Standalone 3D apartment furniture and lighting planner.

Publish this gh-pages branch using GitHub Pages: Settings > Pages > Deploy from a branch > gh-pages > /(root).

Expected URL: https://isebelle.github.io/rino21111.github.io/

No build step is required. Update these static files on gh-pages to update the app. Saved arrangements stay in browser local storage; use Export/Import to transfer from the previous host. See LIGHTING.md for scale and lighting assumptions and vendor/THREE-LICENSE.txt for the bundled renderer license.
